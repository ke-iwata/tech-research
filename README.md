# tech-radar

技術（AI・バックエンド・インフラ・セキュリティ）と金融・投資（マクロ・株式・投資信託・仮想通貨・不動産）の情報を、
毎朝 Claude Code のルーチンで集めて要約し、GitHub Pages のダッシュボードとして公開する自分用の情報収集サイトです。

- `today.md`：今日の要点・収集件数・市況・分野別ヒートマップ・急上昇キーワード・ピックアップ・SNS の声・リリース
- `reader/`：未読を受信箱のようにさばくリーダー（`j` / `k` で移動、`o` 開く、`s` あとで読む、`e` 読了、`m` 分野をミュート）
- `radar.svg`：キーワードを HOT / RISING / WATCH / COOLING のリングに配置したレーダー
- `market.map`：株価指数・為替・金利・暗号資産と、キーワードの言及量を前週比で色分けしたマーケットマップ

データの更新手順は [CLAUDE.md](CLAUDE.md) にあります。要約は自動生成で、誤りを含むことがあります。投資判断は必ず一次情報で確認してください。

ローカル確認：`python3 -m http.server` → http://localhost:8000
